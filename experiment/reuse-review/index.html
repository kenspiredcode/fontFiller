Each test font is shown with source outlines, generated results, and the original character when the font already has one. Accent tests deliberately hide competing accents so that period, caret, hyphen, and o fallbacks are exercised. Quote pairs are independently built from the original opposite quote. A dash indicates an unavailable source or original glyph. Generated fonts are experimental copies for visual review.
